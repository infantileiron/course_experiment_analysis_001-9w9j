# 课程实验分析平台 001

使用Python与Flask实现，可直接操作的Web应用。处理用户曝光、学习和结课事件，按用户去重分析，保存不可覆盖的数据版本、锁定实验及每次分析快照。

## 启动

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py --port 8101
```

打开 http://127.0.0.1:8101 。也可使用上级目录共享虚拟环境 `../.venv/bin/python app.py`。

## 使用

1. 选择无效果、真实提升或分组异常示例，或下载示例CSV后按同一字段上传。
2. 配置UTC半开时间窗口、主要指标、MDE、B组预期占比及预先约定的人群，点击“锁定并分析”。创建后配置不可修改；改口径需要新实验。
3. 查看分流比例检验、用户数、三个指标的效应与区间、Holm校正p值和人群结果；展开配置可追溯数据SHA256指纹。
4. 事后人群分析单独标明探索性质；历史分析可重开，结论附件为包含完整诊断、口径和数据版本的JSON。

CSV字段：`user_id,group,event,time,minutes,segment`。group为A/B，event为exposure/study/complete，time为ISO时间。时间按UTC解释；study分钟必须非负。重复曝光只计算一次，学习事件累加，结课按是否出现计算；跨组曝光者排除并提示，曝光前事件不计入。数据与结果默认保存在项目内data目录，设置APP_DATA_DIR可更换。

## 统计边界

随机分组、用户之间独立、完整埋点是推断前提。窗口尚未结束时提示提前查看限制。分流异常（p<0.001）阻止收益结论。总体三指标使用Holm校正；人群检验在自身族内另行校正，事后探索不能升级为确认性结论。比例差采用正态近似，学习分钟采用Welch检验；展示区间未做多重比较校正。样本规划根据当前A组估计、80%功效及三指标Bonferroni阈值近似计算，并非事后功效证明。护栏有差异时仍需人工确定方向与容忍范围，系统不自动上线。

单机本地使用，不含账号系统或外部数据接入。单次上传32MB、最多50万行。

## 验证

```sh
../.venv/bin/python -m unittest discover -s tests -v
```

覆盖真实提升、重复曝光去重、分流异常、提前查看及配置/结果持久化接口。
